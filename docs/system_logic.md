# RPS量化系统整体设计文档

> cron定时收盘后执行，不构成投资建议，仅自动化筛选与复盘逻辑

## 数据流总览

执行时序（串行，保证文件完整落盘后下游才运行）

```
18:30 cron触发
1. rps_calc.py
    输出：rps_data.json（板块RPS三档入选调出、连续上榜、板块达标率）
    输出：rps_history.json（板块RPS历史序列）
    输出：rps_run_status.json（运行状态：update_date、success、mode、message）
2. 校验 rps_run_status.json success=True 且 update_date==当日，才继续下游
3. recommend.py 日度短线推荐 → recommendations.json
4. daily_review.py 板块量化复盘 → daily_review.json / daily_review.md
5. 每周五：额外执行 recommend_weekly.py → weekly_recommendations.json
```

依赖关系：
- recommend.py / recommend_weekly.py 消费 rps_data.json + daily_review.json（复盘联动扣分）
- daily_review.py：仅消费 rps_data.json、rps_history.json、指数cache，**不重新计算RPS**

> 重要：rps_run_status.json 记录当日 rps_calc 是否成功；周度推荐执行前必须校验
> success=True 且 update_date==当日，否则跳过，避免周五 RPS 计算失败仍基于旧 json 输出错误结果。
> 前端也可读取状态文件提示“今日计算失败/数据过期”，而非静默展示旧结果。

> 复盘驱动选股：recommend.py / recommend_weekly.py 读取 daily_review.json，
> 使用板块健康度、风险信号对选股结果做扣分降级（mature_fatigue 扣 7 分、danger 扣 10 分）。

## 一、日度短线推荐 recommend.py

五层逐层漏斗过滤，全阈值集中在 CONFIG（adjustable），不硬编码散落。

### L1 大盘环境
数据源：上证指数、创业板20日线，涨跌家数，涨跌停统计
- PASS：至少1个指数站上20日线，上涨家数占比≥30%，正常选股
- WARN：不满足PASS，但未触发REJECT，选股继续，全部标的打【大盘偏弱】标签
- REJECT（输出0只）：上涨占比＜25% OR (跌停>40家 且 涨停＜12)
> 组合判据：仅普跌但涨停活跃 = 结构性分化（WARN不否决）；普跌且涨停稀少 = 极端行情（REJECT）。
> 大盘主力资金仅做提示标签，不作为过滤条件，数据缺失跳过。

### L2 候选池
来源：RPS5/RPS10/RPS20≥90入选板块成分股；
1. 同源板块合并（sector_groups 关键词组），计算真实共振板块数，避免题材重复计数拉高板块热度分；
2. 个股全部所属板块在当日调出列表，则剔除候选池；
3. 个股RPS20≥70，不满足不否决，板块热度分减半（板块强而个股弱的“跟班”降权）；
4. 黑名单（blacklist.json 手工维护，大额解禁/减持/利空）在 L2 直接剔除。

### L3 基本面排雷（一票否决）
收盘价≥2元；流通市值≥10亿；PE≤200；资产负债率≤80%；质押≤50%、商誉≤30%（有数据则强制校验，缺失不剔除）
- PE‑TTM＜0：不否决，基本面得分上限5分；
- 财报距今＞180天：基本面得分×0.6，标签【财报陈旧】。

### L4 资金面必达条件（自适应换手率）
- 流通市值＞200亿：换手率 [1%,15%]
- 50‑200亿：换手率 [2%,20%]
- ＜50亿：换手率 [3%,25%]
成交额≥5000万；量比≥1.1；**当日涨停豁免量比校验，标签【涨停无量】**。

### L5 技术共振
7项指标：均线多头排列、MACD金叉、KDJ低位金叉、BOLL突破中轨、个股RPS50≥80、CCI、RSI；
达标≥3项进入打分，命中指标记录进 tags（供后续回测统计）；
RSI>75 / CCI>150 → 标签【技术超买】，技术得分扣3（双超买扣5）。

### 四维评分 100分，门槛总分≥70，且分项最低约束：基本面≥8、资金面≥8
- 板块热度 40：基于去重后共振板块数
- 基本面 20：净利增速、盈利质量、估值
- 资金面 20：换手梯度、量比梯度计分
- 技术面 20：命中指标累计计分

额外软扣分：
- 近5日累计涨幅>25%，总分扣8，标签【短期涨幅过高】
- 复盘联动：mature_fatigue 板块内个股总分扣7；danger 风险板块扣10

标签：
- ≥80：短线优选（不固化持有周期，仅文字提示）
- 70‑79：短线观察

输出：recommendations.json；同时输出 candidate_log.json 记录所有候选股被哪一层过滤及原因（供调参回测）。
输出层控制：同一细分板块最多输出3只。

## 二、周度中线推荐 recommend_weekly.py（每周五执行）

全部基于周K（周五收盘对齐）。全阈值集中在 CONFIG_WEEKLY。

### L1 周度大盘环境
数据源：指数20周均线、周涨跌家数、周MACD
- PASS：至少1个指数站上20周均线，周上涨占比≥40%
- WARN：上涨占比25‑40% 或 周MACD死叉；输出可用，全部标记【中期环境偏弱，建议半仓】
- REJECT（终止输出）：周上涨占比＜25% 且 周涨停家数＜8

### L2 候选池
来源：RPS20入选板块成分股，记录板块连续上榜周数；
同源板块去重；板块标记成熟疲劳则取消连续上榜的额外加分；
前置软过滤个股RPS60≥75（不满足板块热度分减半）；全部板块调出RPS20则剔除；黑名单直接剔除。

### L3 基本面深度排雷
继承日度硬性条件；业绩：净利>0，净利同比≥0；
- 扣非同比＜‑100%：一票否决（明确恶化，疑一次性收益虚增）
- -100% ≤ 扣非同比 ＜ -50%：不否决，基本面得分×0.5（保留反转复苏标的）
- 财报距今＞270天：基本面降级 + 告警标签

### L4 周资金面
周换手率按流通市值自适应（turnover_bands）；单周成交额≥2亿；
> 本周量能≥上周，由硬性过滤改为打分项（vol_expand 计分不否决），允许缩量回踩标的进入。

### L5 周线技术共振
周线7指标 + 收盘创20周新高，达标≥3；记录命中指标；
软扣分：近8周累计涨幅＞80%，扣10分，标签【中期涨幅巨大】。

### 评分
权重：板块热度40 / 基本面30 / 技术面20 / 资金面10；
门槛：总分≥70，且基本面≥15（防纯板块红利混过70分）；
硬性过滤：近2周累计涨幅>30%直接剔除。

输出层：同一细分板块最多输出3只；同时输出 weekly_candidate_log.json 落选原因日志。

## 三、daily_review.py 板块量化复盘

配置全部集中 CONFIG_REVIEW，不硬编码阈值；不输出个股，仅板块维度分析。

### 六大方向
1. **市场定调**：变化量+绝对水位双约束；输出高分板块近120日历史分位；区分全面强 / 结构性强 / 中性 / 弱。
2. **三周期共振**：core核心共振(RPS5∩RPS10∩RPS20)；tough韧性主线；diverge分歧集合（带 diverge_note：良性分歧/逐步衰竭）。
3. **轮动分析**：调入；rank_change≥8排名跃升；调出分类：脉冲退出(≤2天)、老主线终结(≥5天)、普通退出；统计近10日反复轮动板块（翻转≥3次）。
4. **健康度**：板块内部达标率自适应阈值（<15只:40% / 15‑40只:30% / >40只:20%）；成熟主线(连续≥5天)；成熟疲劳(≥8天且达标率跌破阈值)；种子区分高质量种子/脉冲种子。
5. **风险预警**三级 hint/warning/danger：批量调出、高位顶背离、动量衰减。
6. **跟踪清单**：种子池 / 临界晋级池（RPS5∈[88,90)且rank连续2日升，增加板块达标率过滤防小盘脉冲） / 主线分歧池（掉榜天数统计，≥3移入衰竭池）。

### 进阶
- 情绪周期：主标签+多信号复合输出（"sentiment":{"main":"高潮期","signals":["退潮信号"]}，结构化不拼接字符串）；
- 8类风格多标签统计占比，增加“未归类”计数（防板块关键词匹配失败全部丢失）；
- 一致性校验：RPS推导环境 vs recommendations.json 冲突告警，两套结论都写入 daily_review.md 供人工比对。

### 输出
- daily_review.json（结构化，板块数据经 _slim_sector 精简去 stocks 大字段）
- daily_review.md（自动生成块 + 人工笔记块：程序只重写自动块，保留人工复盘笔记，不覆盖用户手工内容）

## 四、模块联动规则

1. recommend.py / recommend_weekly.py 读取 daily_review.json
   - mature_fatigue 成熟疲劳板块：个股得分扣6‑8（实现取7）
   - danger 风险板块：个股得分扣10
   - 不直接一票杀死，但大幅抬高入选门槛，做到“复盘识别风险，选股自动降低该方向权重”。
2. 黑名单文件（blacklist.json）：手工维护利空个股，L2候选池直接剔除。
3. rps_run_status.json：串行执行状态记录，下游（周推荐）与前端消费，失败不静默。

## 五、三者对比

| 模块 | 时间维度 | 数据源来源 | 核心重心 | 输出物 |
|---|---|---|---|---|
| 日推荐 | 日线 | RPS5/10/20板块成分股 | 资金动量，短线个股 | recommendations.json |
| 周推荐 | 周K(周五) | RPS20板块成分股 | 业绩持续性，中线波段 | weekly_recommendations.json |
| 每日复盘 | 日板块 | RPS历史数据 | 轮动、健康度、风险信号 | daily_review.json/.md |

## 六、通用机制

- **落选原因日志**：candidate_log.json / weekly_candidate_log.json 记录每只候选股被过滤的层与原因，用于调参迭代、回测归因。
- **输出同板块控制**：日/周推荐每细分板块最多输出3只，防主线集中时推荐列表高度同质。
- **运行状态**：rps_run_status.json 记录当日计算成败，前端可展示“今日计算失败”告警，不展示过期结果。
